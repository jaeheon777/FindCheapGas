# FindCheapGas

내 차 연비와 할인 카드를 반영하고 주유소까지 가는 비용까지 더해서, **내 조건에 따른 예상 총비용이 가장 낮은 주유소**를 찾아주는 안드로이드 앱입니다.

표시 가격이 가장 싼 주유소가 항상 이득인 것은 아닙니다. 멀리 있는 주유소는 가는 데 기름을 더 쓰고, 카드나 멤버십 할인을 받으면 표시 가격이 더 비싼 주유소가 실제로는 더 쌀 수 있습니다.
이 앱은 주변 주유소 가격에 내 차 정보와 할인 정보를 더해서 "여기서 넣으면 얼마나 이득일지"를 추정하고, 지도와 목록에 그 결과를 보여줍니다.

## 이 앱이 계산하는 것

유가 정보는 오피넷(한국석유공사)에서 가져옵니다. 이 앱은 그 가격에 사용자 조건을 더해서 아래 값을 계산하고, 이 값을 기준으로 주유소 순위를 매깁니다.

| 계산 항목 | 내용 |
|---|---|
| 할인 반영 기름값 | 브랜드별 리터당 할인을 적용하되, 1회 할인 한도를 넘지 않게 계산합니다. |
| 주유소까지 가는 연료비 | 주유소까지의 도로 거리를 추정하고, 내 차 연비로 그 거리를 가는 데 드는 연료비를 계산합니다. |
| 예상 총비용 | 할인 반영 기름값과 주유소까지 가는 연료비를 더한 값입니다. 목록의 기본 정렬 기준입니다. |
| 예상 이득 | 가장 가까운 주유소에서 넣을 때보다 예상 총비용이 얼마나 적은지 보여줍니다. 지도 마커 색도 이 값으로 정합니다. |

같은 계산을 현재 위치뿐 아니라 집과 회사 근처에도 적용해서 어디서 넣는 게 유리한지 비교하고, 홈 화면 위젯으로도 보여줍니다.

## 예상 이득 계산 방식

가장 가까운 주유소를 기준으로 삼고, 각 주유소에서 넣었을 때 예상 총비용이 기준보다 얼마나 적은지 계산합니다.

```
할인액      = min(리터당 할인 × 주유량, 1회 할인 한도)
기름값      = 표시 가격 × 주유량 − 할인액
이동 거리   = 직선거리 × 1.4   (도로 거리 추정, 편도)
이동 비용   = 이동 거리 ÷ 연비 × 표시 가격
예상 총비용 = 기름값 + 이동 비용
예상 이득   = 기준 주유소 예상 총비용 − 이 주유소 예상 총비용
```

예시 1 (연비 12km/L, 주유량 40L, 할인 없음)

| | 가장 가까운 주유소 | 3km 떨어진 주유소 |
|---|---|---|
| 표시 가격 | 1,700원 (0.5km) | 1,640원 (3km) |
| 기름값 | 68,000원 | 65,600원 |
| 이동 비용 | 약 99원 | 약 574원 |
| 예상 총비용 | 68,099원 | 66,174원 |
| 예상 이득 | 기준 | **약 1,925원 이득** |

예시 2 (할인 한도)

리터당 100원 할인, 1회 할인 한도 3,000원인 카드로 40L를 넣으면 할인액은 4,000원이 아니라 3,000원입니다. 한도를 입력하지 않으면 한도 없이 계산합니다.

### 위치끼리 비교할 때

집·회사 기준 비교처럼 출발 위치가 다른 결과끼리는 예상 이득이 아니라 예상 총비용으로 비교합니다. 예상 이득은 그 위치에서 가장 가까운 주유소를 기준으로 한 값이라 위치마다 기준이 달라서 서로 비교할 수 없고, 예상 총비용은 같은 양을 넣는 데 드는 돈이라 위치끼리 비교할 수 있습니다.

### 계산의 가정과 한계

- **편도 거리**: 조회 위치에서 주유소까지 가는 거리만 계산합니다. 주유한 뒤에는 원래 가려던 곳으로 이어서 간다고 보고, 돌아오는 거리는 넣지 않습니다.
- **조회 위치**: 기본은 현재 위치이고, 장소나 주유소 이름을 검색해서 고르면 그 위치가 조회 위치가 됩니다. 지도를 옮긴 뒤 "이 지역에서 다시 검색"을 누르면 지도 중심이 조회 위치가 되고, "역삼1동 기준"처럼 동 이름으로 표시합니다(이름을 얻지 못하면 "지도 중심 기준"). 거리, 이동 비용, 기준 주유소, 예상 이득은 모두 "조회 위치에서 출발한다면"으로 계산합니다. 검색한 위치로 조회 중이면 지도 위에 "강남역 기준" 같은 표시가 나오고, 목록 위쪽과 상세 화면에도 "강남역에서 0.7km"처럼 조회 위치 이름을 보여줍니다.
- **도로 거리 계수 1.4**: 실제 도로는 직선이 아니어서 도로 거리는 직선거리보다 깁니다. 미국 전역 66,011곳에서 가장 가까운 병원까지의 운전 거리와 직선거리를 비교한 연구에서 그 비율(우회 계수)이 1.417로 나타났고, 연구진은 직선거리에 약 1.4를 곱하면 운전 거리의 적절한 대체값이 된다고 결론지었습니다 [1]. 이 앱은 이 값을 따릅니다.
  - 미국 자료이므로 국내 도로에서는 차이가 있을 수 있습니다.
  - 짧은 거리일수록 우회 비율이 더 커지는 경향이 있어 [2], 5km 이내 거리에서는 실제 거리가 더 길 수 있습니다.
  - 강, 다리, 일방통행, 고속도로 진출입 때문에 실제 거리와 크게 다를 수 있고, 이 경우 순위가 바뀔 수 있습니다.
  - 주유소마다 길찾기 API를 부르면 호출이 너무 많아져서 이 방식으로 추정합니다. 화면에는 추정치임을 표시합니다.
  - 2026년 11월 4일에 강남역에서 반경 5km 안의 실제 주유소 19곳까지 카카오모빌리티 자동차 길찾기 도로 거리를 직선거리와 비교했습니다. 합계 기준 비율(도로 거리 합 ÷ 직선거리 합)은 1.455, 중앙값은 1.419입니다.
    - 구간별 합계 기준 비율은 0\~1km 1.85(5곳), 1\~3km 1.52(7곳), 3\~5km 1.36(7곳)으로, 가까울수록 우회 비율이 컸습니다.
    - 전체로는 1.4와 비슷해서 계수 1.4를 그대로 씁니다. README 예시 1의 3km 주유소 이동 비용은 1.4일 때 약 574원, 1.455일 때 약 597원으로 차이가 작습니다. 다만 1km 이내 주유소는 실제 이동 거리가 추정보다 길 수 있습니다.
    - 출발점이 한 곳이고 측정 시점의 경로 하나만 반영한 결과입니다. 측정 결과는 [docs/road-distance-check.csv](docs/road-distance-check.csv)에 있습니다.
- **할인 조건**: 리터당 할인과 1회 할인 한도만 반영합니다. 전월 실적, 월 누적 한도 같은 카드사 조건은 반영하지 않습니다.
  - 1회 할인 한도를 비워 두면 한도 없이 계산하고, 설정 화면과 계산 내역에 "한도 미적용"이라고 표시합니다. 비워 둔 것을 무제한 할인으로 오해하지 않게 하기 위해서입니다.
  - 한도를 비워 둔 상태에서 할인액이 5,000원 이상이면, 계산 내역에 "한도가 있다면 실제 할인은 이보다 적을 수 있어요"라고 안내합니다.
- **기준 주유소**: 숨긴 브랜드와 브랜드 빠른 필터를 먼저 적용하고, 화면에 보이는 주유소 중 가장 가까운 곳을 기준으로 삼습니다. 기준 주유소의 브랜드에 할인이 있으면 기준에도 할인을 적용합니다.
- **기본값**: 내 차 정보를 입력하지 않으면 연비 12km/L, 주유량 40L로 계산합니다.
- **계산 기준 표시**: 어떤 조건으로 계산했는지 항상 화면에 보여줍니다.
  - 기본값을 쓰는 경우: `연비 12km/L · 40L 기준 (기본값)`
  - 직접 입력한 경우: `내 차 기준 · 연비 15km/L · 50L`
  - 목록 위쪽(지도 탭의 이득 1위 카드), 상세 화면의 계산 내역, 홈 화면 위젯에 표시하고, 목록 위쪽의 문구를 누르면 내 차 정보 화면이 열립니다.

## 주요 기능

기능을 4단계로 나누고 순서대로 개발합니다. 앱의 차별점인 예상 이득 계산은 2단계에 두어 먼저 완성합니다.

### 1단계 - 기본 기능

| 기능 | 설명 |
|---|---|
| 현재 위치 지도 | 앱을 실행하면 위치 권한을 요청하고, 현재 위치를 중심으로 지도를 띄웁니다. 현재 위치는 점으로 표시합니다. |
| 주변 주유소 표시 | 주변 주유소를 가격과 함께 마커로 표시하고, 아래 목록에 보여줍니다. |
| 유종 선택 | 휘발유, 경유, 고급휘발유, LPG 중에서 선택합니다. |
| 반경 선택 | 1km, 3km, 5km 중에서 선택합니다. |
| 정렬 | 목록을 가격순 또는 거리순으로 정렬합니다. |
| 상세 정보 | 주유소를 누르면 주소, 전화번호, 유종별 가격, 부가시설(셀프, 세차장, 편의점 등)을 보여줍니다. |

### 2단계 - 차별화 기능

| 기능 | 설명 |
|---|---|
| 내 차 정보 | 처음 실행할 때 연비와 평소 주유량을 입력받습니다. 건너뛸 수 있고, 설정에서 바꿀 수 있습니다. 건너뛰면 기본값으로 계산하고, 기본값으로 계산 중이라는 것을 화면에 표시합니다. |
| 예상 이득 계산 | 할인과 이동 비용을 반영해서 주유소마다 예상 이득을 계산합니다. 목록에 "약 OO원 이득"을 표시하고, 기본 정렬을 예상 이득순으로 합니다. 목록 위쪽에 계산 기준(연비, 주유량)을 항상 표시합니다. |
| 이득 색깔 마커 | 마커 색을 예상 이득 기준으로 칠합니다. 1,000원 이상 이득은 초록, 1,000원 이내 차이는 회색, 1,000원 이상 손해는 빨강입니다. |
| 내 브랜드 설정 | 브랜드마다 리터당 할인, 1회 할인 한도, 선호, 숨기기를 정합니다. 할인은 한도 안에서 계산에 반영하고, 숨긴 브랜드는 표시하지 않습니다. 선호 브랜드는 예상 이득순 정렬에서만 정렬용 점수에 500원을 더해 위로 올립니다. 화면에 보이는 이득 금액과 "이득 1위"는 실제 예상 이득 그대로입니다. 한도를 비워 두면 "한도 미적용"으로 표시합니다. 선호와 숨기기는 함께 켤 수 없습니다. |
| 브랜드 빠른 필터 | 지도 위 필터에서 원하는 브랜드만 보거나, 할인 브랜드만 / 선호 브랜드만 볼 수 있습니다. 여러 개를 고르면 하나라도 맞는 주유소를 보여주고, 고른 값은 앱을 다시 켜도 유지합니다. 숨긴 브랜드는 필터 메뉴에도 나오지 않습니다. |

### 3단계 - 주요 기능

| 기능 | 설명 |
|---|---|
| 장소 검색 | 장소(예: 강남역, 해운대구)를 검색하면 지도를 해당 위치로 옮기고 주변 주유소를 보여줍니다. |
| 주유소 이름 검색 | 주유소 이름으로 검색합니다. |
| 즐겨찾기 | 자주 가는 주유소를 최대 20곳까지 저장하고 즐겨찾기 탭에 모아서 봅니다. 지금 고른 유종의 가격, 조회 위치에서의 거리, 예상 이득을 함께 보여줍니다. 조회 위치에서 5km 밖인 주유소는 예상 이득을 계산하지 않습니다. 가격은 저장하지 않고 볼 때마다 가져옵니다. |
| 길찾기 | 버튼을 누르면 카카오맵 또는 티맵 앱을 열고 해당 주유소를 목적지로 자동 입력합니다. 실제 길안내는 각 앱이 담당합니다. 앱이 설치되어 있지 않으면 플레이스토어 설치 페이지로 이동합니다. |
| 이 지역에서 다시 검색 | 지도를 옮긴 뒤 버튼을 누르면 지도 중심을 기준으로 다시 검색합니다. |

### 4단계 - 추가 기능

| 기능 | 설명 |
|---|---|
| 집·회사 기준 비교 | 집과 회사 위치를 저장해 두고, 지금 조회 위치 / 집 근처 / 회사 근처의 이득 1위 주유소를 예상 총비용으로 비교해서 어디서 넣는 게 가장 저렴할지 한 화면에서 보여줍니다. 집·회사 위치는 이 기기에만 저장하고 백업에서도 뺍니다. |
| 홈 화면 위젯 | 앱을 열지 않아도 홈 화면에서 이득 1위 주유소와 가격, 이득 금액을 보여줍니다. 위젯을 놓을 때 집 / 회사 중 하나를 고르고, 설정에서 등록한 그 위치 기준으로 보여주므로 위치 권한(백그라운드 위치 포함)을 쓰지 않습니다. 이득 1위는 집·회사 기준 비교 카드와 같은 계산으로 고릅니다. |
| 7일 가격 추이 | 주유소 상세 화면에서 지금 고른 유종의 최근 7일 전국 평균가를 꺾은선 그래프로 보여주고, 첫날보다 얼마나 오르거나 내렸는지 한 줄로 적습니다. 가격을 예측하지 않고 지난 추이만 보여줍니다. |
| 평균가 비교 | 주유소 상세 화면에서 지금 고른 유종의 표시 가격(할인 전)을 전국 평균가, 그 주유소가 있는 시도의 평균가와 비교해서 리터당 차이와 내 주유량 기준 차이를 보여줍니다. 평균가도 표시 가격이라 할인은 넣지 않습니다. |
| 다크 모드 | 설정 탭에서 화면 테마를 시스템 설정 따르기(기본) / 밝게 / 어둡게 중에서 고릅니다. 지도는 카카오맵 SDK가 기본 스타일만 제공해서 밝은 그대로 두고, 지도 위 검색창·필터·버튼과 아래 시트, 나머지 화면을 어둡게 바꿉니다. 홈 화면 위젯은 런처가 그리므로 앱 설정이 아니라 휴대폰의 다크 모드 설정을 따릅니다. |
| API 사용량 표시 | 설정 탭에 오늘 오피넷 호출 횟수를 "오늘 12회 / 300회"와 진행 막대로 보여줍니다. 250회부터 경고 색으로 "한도에 가까워졌어요", 300회면 "오늘 한도에 도달했어요. 저장된 결과만 볼 수 있어요"를 표시합니다. 오피넷 호출만 세고 카카오 API는 세지 않습니다. |

### 여유가 있으면 추가할 기능

| 기능 | 설명 |
|---|---|
| 가는 길에 들르기 | 목적지를 입력하면 경로 근처 주유소 중 돌아가는 거리가 적고 이득이 큰 곳을 추천합니다. |
| 목표가 알림 | 즐겨찾기 주유소가 정한 가격 아래로 내려가면 알림을 보냅니다. |

## 화면 구성

```
로딩 화면 - 위치 권한 요청
   │
   ▼
처음 실행 시 - 내 차 정보 입력 (큰 제목 "내 차 정보를 알려주세요"와 한 줄 설명, 연비, 평소 주유량, 주로 넣는 유종,
               입력칸마다 작은 안내 글자, 아래에 고정한 "저장하고 시작하기"와 "건너뛰기", 키보드가 올라와도 버튼이 보임)
   │
   ▼
메인 화면 (하단 탭 3개)
 ├─ 지도 탭 (첫 화면)
 │    - 상단: 검색창(장소 / 주유소 이름 선택), 필터 칩(휘발유, 5km, 브랜드)
 │      검색창에 입력하는 동안(키보드가 보이는 동안)은 아래 시트를 숨기고, 키보드가 내려가면 내린 상태로 다시 보여줌
 │    - 중앙: 지도 (현재 위치, 예상 이득 색깔 가격 마커)
 │    - 아래 시트는 내림 / 올림 두 단계 (끌어서 바꾸거나 손잡이를 누르면 바뀜, 손잡이 접근성 설명은 "목록 펼치기" / "목록 접기")
 │      시트를 올린 상태에서 시트 밖 지도를 누르면 시트만 내림 (그 누름으로 마커를 고르거나 지도를 바꾸지 않음, 시트 안을 누르면 그대로)
 │      시트를 올린 상태에서 지도를 끌면 시트를 내리고 지도는 손가락을 따라 움직임
 │      시트를 올린 상태에서 유종·반경·브랜드 칩을 누르면 시트를 내린 뒤 메뉴를 엶 (메뉴가 시트에 겹치지 않음, 목록 머리줄의 정렬 메뉴는 시트를 그대로 둠)
 │    - 시트를 내린 상태: 이득 1위 카드 한 장
 │        주인공 숫자 "약 2,583원 아낄 수 있어요" (1,000원 미만이면 "가장 가까운 곳과 비슷해요")
 │        상호 / 브랜드 · 거리 · 가격, 길찾기 버튼
 │        계산 기준 문구 (예: 연비 12km/L · 40L 기준 (기본값), 누르면 내 차 정보)
 │        마커를 누르면 그 주유소로 바뀌고("약 1,220원 더 들어요"), "이득 1위 보기"로 돌아감
 │        카드를 누르면 상세 화면, 불러오는 중·주유소 없음·오류(키 문제 포함)·위치 권한·기기 위치 꺼짐 안내(서울시청 기준이라는 것과 권한 허용 / 설정에서 권한 허용하기 / 위치 켜기 버튼)도 이 자리에 표시
 │    - 시트를 올린 상태: 카드 아래로 주유소 목록 (시트를 내렸다 올리거나 정렬·반경·유종·필터를 바꾸면 맨 위부터)
 │        머리줄: "주변 23곳 · 내 위치 기준", 정렬(예상 이득순 / 가격순 / 거리순), 마커 색 안내 (?)
 │        한 줄: 상호(선호 브랜드는 ★), 브랜드 · 거리와 배지 하나(이득 1위 > 할인 적용 > 최저가)
 │               오른쪽에 가격과 "약 2,583원 아껴요" / "비슷해요" / "약 1,200원 더 들어요"
 │
 ├─ 즐겨찾기 탭
 │    - 맨 위 작은 글자 한 줄: 계산 기준 · 유종 · 반경 · 조회 위치 (누르면 내 차 정보)
 │    - 주인공 카드: 집·회사 기준 비교의 결론
 │        "회사 근처에서 넣으면 가장 저렴해요"와 그 카드의 예상 총비용(큰 숫자)
 │        모든 카드가 가장 저렴한 카드와 1,000원 미만 차이면 "어디서 넣어도 비슷해요"와 가장 저렴한 카드의 예상 총비용
 │        비교할 수 있는 카드가 두 장보다 적으면 큰 숫자 없이 짧은 안내만
 │    - 집·회사 기준 비교: 카드 세 장 (지금 조회 위치 / 집 근처 / 회사 근처)
 │        제목, 이득 1위 상호, 작은 보조 글자 한 줄(브랜드 · 거리 · 가격 · 가져온 시각)
 │        오른쪽에 예상 총비용과 "가장 저렴" 배지(라임 바탕) 또는 "약 1,200원 더 들어요"(빨강), 1,000원 미만 차이면 "비슷해요"(회색, 지도 탭과 같은 기준)
 │        등록하지 않은 곳은 점선 테두리 안에 "집 위치 등록하기" 버튼 하나, 카드를 누르면 지도 탭에서 그 위치 기준으로 이득 1위 선택
 │    - 저장한 주유소(최근 저장순, 최대 20곳): 목록 한 줄 조각으로 상호 / 브랜드 · 거리, 가격 / 예상 이득 설명
 │        이유는 짧게 ("5km 밖이라 계산 안 해요", "이 유종을 팔지 않아요", "찾을 수 없어요"), 30분 넘은 가격은 배지
 │        주소는 상세 화면에서만, 찾을 수 없는 주유소는 삭제 버튼
 │        비어 있으면 가운데에 안내와 "지도에서 주유소 찾기" 버튼
 │    - 당겨서 새로고침, 왼쪽으로 밀거나 길게 눌러 메뉴로 삭제(실행 취소 가능)
 │
 └─ 설정 탭 (회색 바탕에 흰 카드로 묶은 목록, 한 줄은 왼쪽 이름 · 오른쪽 지금 값 >, 긴 설명은 카드 아래 작은 글자)
      - 내 차: 내 차 정보 (연비 15km/L · 40L), 아래에 기본값 사용 여부와 작은 "기본값으로 되돌리기" 버튼
      - 할인과 브랜드: 내 브랜드 (할인·선호·숨김 요약, 누르면 흰 카드로 묶은 브랜드 목록, 줄을 누르면 할인, 1회 할인 한도(비우면 "한도 미적용"), 선호, 숨기기 시트)
      - 위치: 집, 회사 (등록한 장소 이름 또는 "등록 안 함", 누르면 집·회사 두 줄 카드에서 장소 검색으로 등록 / 바꾸기 / 지우기, 카드 아래 개인정보 안내)
      - 지도 기본값: 기본 유종, 기본 반경 (지도 탭에서 마지막으로 고른 값과 같은 값, 바꾸면 지도 탭에도 바로 반영)
      - 화면: 화면 테마 (시스템 설정 따르기 / 밝게 / 어둡게, 위젯은 휴대폰의 다크 모드 설정을 따름)
      - 사용량: 오늘 오피넷 사용량 ("오늘 12회 / 300회", 진행 막대, 250회부터 경고), 아래에 자정에 0회로 초기화,
        오피넷 호출만 셈, 가짜 데이터 모드면 오피넷을 호출하지 않는다는 안내

주유소 상세 화면 (마커나 목록 항목, 이득 1위 카드를 누르면 열림)
 - 맨 위 카드: 이름, 브랜드 · 조회 위치에서 거리
     주인공 숫자 "약 2,583원 아낄 수 있어요" (손해면 "약 1,200원 더 들어요", 비슷하면 "가장 가까운 곳과 비슷해요")
     그 아래 "역삼셀프주유소보다 · 내 차 기준 · 연비 15km/L · 40L" (기준 주유소 이름 + 계산 기준)
     기준 주유소 자신이면 "가장 가까운 주유소예요" / "다른 곳과 비교하는 기준이에요"
     고른 유종 가격 (예: 휘발유 1,579원)
 - "계산 내역 보기"를 누르면 예상 이득 계산 내역을 펼침 (계산 기준, 기름값 차이, 할인액과 한도 적용 여부, 이동 비용, 회전해도 펼침 상태 유지)
 - 가격 카드: 유종별 가격
 - 주유소 정보 카드: 주소, 전화번호(누르면 전화 걸기 화면), 셀프 여부, 세차장, 편의점, 경정비 여부
 - 평균가 대비 카드: 고른 유종의 표시 가격(할인 전)과 전국 평균, 시도 평균의 리터당 차이, 내 주유량 기준 차이
   (예: 전국 평균 1,712원보다 리터당 41원 저렴해요 / 40L 기준 약 1,640원 저렴해요, 그 유종을 팔지 않으면 "이 유종을 팔지 않아요")
 - 7일 가격 추이 카드: 최근 7일 전국 평균 꺾은선 그래프(가장 높은 값, 가장 낮은 값, 마지막 날 값 표시)와
   "6일 전(10/31)보다 약 12원 올랐어요" 같은 지난 변화 한 줄
 - 평균가와 추이는 따로 불러오고, 못 불러오면 그 부분만 한도 도달 / 연결 없음 / 불러오지 못함 안내로 바뀜
 - 즐겨찾기(북마크) / 길찾기 버튼, 즐겨찾기 탭에서 열었으면 지도에서 보기 버튼

홈 화면 위젯 (기본 가로 4칸 · 세로 2칸, 크기 조절 가능)
 - 위젯을 놓을 때 집 근처 / 회사 근처 중 하나를 고름 (위젯마다 따로, Android 12 이상은 길게 눌러 다시 고르기)
 - 제목("집 근처", 주소는 표시하지 않음), 이득 1위 주유소 상호, 가격, 예상 이득, 브랜드 · 그 위치에서 거리
 - 계산 기준(예: 12km/L · 40L (기본값)), 가격을 가져온 시각(예: 오후 3:20 갱신), 새로고침 버튼
 - 작게 줄이면 상호, 가격, 예상 이득만 표시
 - 위치를 등록하지 않았으면 "앱에서 집 위치를 등록해 주세요"(누르면 집·회사 위치 화면), 주유소 없음·한도 도달·연결 없음은 짧은 안내
 - 가져오지 못했는데 이전 결과가 있으면 이전 결과에 "갱신 실패"를 붙여서 표시
 - 누르면 앱이 열리고 지도 탭에서 그 위치("집 기준")로 조회해서 이득 1위 주유소를 선택
```

## 동작 방식

앱을 실행했을 때 주유소가 지도에 표시되기까지의 흐름은 다음과 같습니다.

```mermaid
flowchart TD
    A[앱 실행] --> B{위치 권한 허용}
    B -- 허용 --> C[현재 위치 가져오기]
    B -- 거부 --> D[기본 위치로 지도 표시<br>권한 안내 메시지]
    C --> E[좌표 변환<br>WGS84 → KATEC]
    E --> F[오피넷 API로<br>주변 주유소 조회]
    F --> G[좌표 변환<br>KATEC → WGS84]
    G --> H[예상 이득 계산<br>내 차 정보, 브랜드 할인 반영]
    H --> I[지도에 이득 색깔 마커 표시<br>하단 목록 표시]
```

장소나 주유소 이름을 검색해서 결과를 고르거나 "이 지역에서 다시 검색"을 누르면, 현재 위치 대신 고른 위치(또는 지도 중심)를 조회 위치로 삼아 좌표 변환부터 같은 순서로 처리합니다. 지도를 움직이기만 해서는 조회하지 않고, 지도 중심이 조회 위치에서 고른 반경만큼 떨어졌을 때 "이 지역에서 다시 검색" 버튼을 보여줍니다 (반경 1km는 1km, 3km와 5km는 3km). 이 버튼은 아래 시트를 내린 상태에서만 보이고, 시트를 올리면 숨겼다가 다시 내리면 보여줍니다. 내 위치 버튼이나 "강남역 기준" 표시의 X를 누르면 다시 현재 위치 기준으로 돌아갑니다.

### 위치를 얻지 못할 때

위치 권한이 없거나 기기 위치가 꺼져 있어 내 위치를 얻지 못하면 기본 위치(서울시청)로 조회하고, 이득 1위 카드 자리에 그 이유와 버튼을 보여줍니다.

| 상황 | 안내 | 버튼 |
|---|---|---|
| 위치 권한 거부 | 위치 권한이 없어 서울시청 기준으로 보여드려요 | 권한 허용 (권한 창) |
| 위치 권한 "다시 묻지 않음" | 위치 권한이 꺼져 있어 서울시청 기준으로 보여드려요 | 설정에서 권한 허용하기 (앱 설정 화면) |
| 기기 위치 꺼짐 | 위치가 꺼져 있어 서울시청 기준으로 보여드려요 | 위치 켜기 (위치 설정 화면) |

설정 화면에서 권한을 허용하거나 위치를 켜고 돌아오면 바로 내 위치로 다시 조회합니다. 기기 위치가 꺼져 있는데 기기에 남아 있던 마지막 위치를 얻었으면 그 위치로 조회하고, "위치가 꺼져 있어 마지막으로 확인한 위치 기준으로 보여드려요"와 위치 켜기 버튼을 잠깐 보여줍니다.

### 좌표 변환

휴대폰 GPS와 카카오맵은 위도·경도(WGS84) 좌표를 사용하고, 오피넷 API는 KATEC 좌표를 사용합니다.
따라서 오피넷에 요청할 때는 현재 위치를 KATEC으로 변환하고, 응답으로 받은 주유소 위치는 다시 WGS84로 변환해서 지도에 표시합니다.

## 외부 API

모두 무료로 사용할 수 있습니다. 키 발급 방법은 [실행 방법](#실행-방법)에 정리했습니다.

오피넷과 카카오 로컬 API 요청은 연결과 응답 읽기에 각각 10초 시간 제한을 둡니다. 연결이 없거나(비행기 모드 등) 시간이 넘으면 화면마다 "인터넷에 연결할 수 없어요"처럼 연결 문제라고 보여주고, 지도 탭·상세 화면·검색은 다시 시도 버튼, 즐겨찾기와 집·회사 비교는 당겨서 새로고침, 위젯은 이전 결과에 "갱신 실패 · 연결 없음"을 붙여 보여줍니다. 연결이 돌아온 뒤 다시 시도하면 정상으로 돌아옵니다.

### 오피넷 유가정보 API (한국석유공사)

| API | 용도 |
|---|---|
| 반경 내 주유소 | 현재 위치 주변 주유소와 가격 조회 (최대 반경 5km) |
| 주유소 상세정보 | 주소, 전화번호, 유종별 가격, 부가시설 조회 |
| 상호로 주유소 검색 | 주유소 이름 검색 |
| 전국 / 시도별 평균가격 | 평균가 비교 |
| 최근 7일간 전국 일일 평균가격 | 7일 가격 추이 |

유종 코드는 휘발유 `B027`, 경유 `D047`, 고급휘발유 `B034`, LPG `K015`입니다.

평균가 API 세 개는 유종(`prodcd`)과 시도(`sido`), 날짜(`date`)를 넣지 않고 부릅니다. 이렇게 부르면 전국 평균은 모든 유종, 시도별 평균은 모든 시도의 모든 유종, 최근 7일 평균은 7일 동안의 모든 유종이 한 번에 오기 때문에, 유종마다 따로 부르지 않고 한 번 받은 결과를 4개 유종에 같이 씁니다. 실내등유처럼 앱이 다루지 않는 유종은 뺍니다. 시도는 상세정보 주소의 첫 단어(예: 서울특별시, 충청북도, 강원특별자치도)로 정하고 오피넷 시도 이름(서울, 충북, 강원)과 맞춥니다.

`local.properties`에 `OPINET_API_KEY`가 없으면 오피넷을 부르지 않고, 지도 탭, 상세 화면(평균가, 7일 추이 포함), 주유소 이름 검색, 즐겨찾기, 집·회사 비교, 위젯에 "오피넷 API 키가 설정되지 않았어요"처럼 키 문제라는 것을 보여줍니다. 다시 시도해도 같은 결과라 다시 시도 버튼은 두지 않습니다. 키가 틀린 경우의 응답 형식은 확인할 수 있는 자료가 없어서 다른 오피넷 오류와 같이 "유가 정보를 불러오지 못했어요"로 보여줍니다.

### 카카오맵 Android SDK

지도 표시, 마커 표시, 현재 위치 표시에 사용합니다. 네이티브 앱 키가 없거나 인증에 실패하면(키 해시 미등록 등) 지도 자리에 "지도를 불러오지 못했어요"와 확인할 내용을 보여주고, 이득 1위 카드와 주유소 목록은 지도 없이도 그대로 씁니다.

### 카카오 로컬 API

지도 탭의 장소 검색과 "이 지역에서 다시 검색"의 조회 위치 이름에 사용합니다.

- 장소 검색: 키워드 검색(`/v2/local/search/keyword.json`)으로 찾고, 결과가 없으면 주소 검색(`/v2/local/search/address.json`)을 한 번 더 해 봅니다.
- 좌표 → 행정구역 변환(`/v2/local/geo/coord2regioncode.json`): "이 지역에서 다시 검색"을 누르면 지도 중심 좌표의 동 이름(행정동 우선, 예: 역삼1동)을 얻어 "역삼1동 기준"으로 표시합니다. 이름은 표시용이라 실패하거나 키 오류여도 "지도 중심 기준"으로 표시하고 주변 조회는 그대로 합니다.

 REST API 키는 `Authorization: KakaoAK {키}` 헤더로 보내고, 키와 헤더는 로그에 남기지 않습니다. 키가 비었거나 틀리면(401, 403) 장소 검색을 사용할 수 없다고 안내합니다.

오피넷 호출이 아니므로 하루 300회 제한과 관계없고, 가짜 데이터 모드에서도 실제 카카오 API를 사용합니다. 가짜 주유소 데이터는 강남역 주변에만 있어서, 가짜 데이터 모드에서 강남역에서 5km보다 먼 곳을 고르면 강남역 주변 주유소만 볼 수 있다고 안내합니다. 집·회사 위치 등록에도 같은 장소 검색을 사용합니다.

### 카카오모빌리티 길찾기 API

앱 기능에는 사용하지 않고, 도로 거리 계수 1.4를 검증할 때 한 번만 사용했습니다. 자동차 길찾기(`/v1/directions`, 추천 경로)로 표본 주유소까지의 도로 거리를 구해서 직선거리와 비교했습니다. 표본 주유소는 카카오 로컬 API 카테고리 검색(주유소)으로 골랐습니다.

## API 호출 제한 대응

오피넷 무료 API는 하루 호출 횟수가 300회로 제한되어 있습니다.
실제로 앱을 사용할 때는 한 번에 5~10회 정도라 문제가 없지만, 개발 중에 앱을 반복해서 실행하면 금방 한도에 도달합니다.
그래서 아래 방식을 적용합니다.

| 방식 | 내용 |
|---|---|
| 가짜 데이터 모드 | 실제 API 응답과 같은 구조의 JSON 파일을 두고, 개발 중에는 이 파일을 읽습니다. `local.properties`의 `USE_MOCK_DATA` 값으로 전환합니다. |
| 응답 캐싱 | 같은 위치와 유종으로 조회한 결과는 일정 시간(10~30분) 동안 저장해 두고 재사용합니다. 주유소 상세정보는 주유소별로, 주유소 이름 검색 결과는 같은 검색어별로 30분 동안 재사용합니다. 집·회사 기준 비교는 탭을 열 때 같은 위치·유종의 주변 조회 결과가 3시간 안이면 그대로 쓰고 "약 1시간 전 가격"처럼 보여줍니다. 즐겨찾기 탭을 열 때는 30분이 지난 상세정보도 하루 동안은 그대로 씁니다. 전국·시도별 평균가는 3시간 동안, 최근 7일 전국 평균가는 같은 날짜 안에서 재사용합니다. 평균가 캐시는 다시 받으면 되는 값이라 Room이 아니라 SharedPreferences에 둡니다. 유가는 하루에 몇 번만 바뀌기 때문에 이 정도면 충분합니다. |
| 앱 안에서 다시 계산 | 정렬, 반경, 브랜드 필터, 내 차 정보, 할인 설정을 바꿀 때는 API를 다시 부르지 않고 이미 받은 목록으로 다시 계산합니다. 오피넷에는 항상 최대 반경 5km로 요청해 두고, 1km나 3km를 고르면 받아 둔 목록에서 그 안의 주유소만 보여줍니다. 유종을 바꿀 때만 새로 조회합니다. |
| 수동 재검색 | 지도를 움직일 때마다 자동으로 조회하지 않고, "이 지역에서 다시 검색" 버튼을 눌렀을 때만 조회합니다. |
| 검색 최소화 | 입력 중에는 검색하지 않고, 검색 버튼이나 키보드의 검색 키를 눌렀을 때만 검색합니다. 주유소 이름 검색은 두 글자 이상일 때만 오피넷을 부르고, 같은 검색을 연달아 누르면 한 번만 요청합니다. |
| 상세 조회 최소화 | 주변 검색 결과에 이름, 가격, 거리, 좌표가 포함되어 있으므로 상세 정보는 주유소를 눌렀을 때만 조회합니다. |
| 갱신 주기 제한 | 즐겨찾기 가격은 지도 탭이 받아 둔 주변 목록(조회 위치 5km, 같은 유종)에 그 주유소가 있으면 그 가격을 쓰고, 없을 때만 상세정보를 가져옵니다. 탭을 열 때는 하루 안에 가져온 상세정보가 있으면 그대로 쓰고, 당겨서 새로고침할 때만 30분이 지난 것을 다시 가져옵니다. 즐겨찾기는 최대 20곳이라 한 번에 많아야 20회입니다. 집·회사 비교는 탭을 열 때 3시간이 지났거나 유종·위치가 바뀌었을 때, 그리고 당겨서 새로고침할 때 20분이 지난 것만 다시 가져옵니다. 집과 회사 두 곳이라 한 번에 많아야 2회이고, 지금 조회 위치 카드는 지도 탭이 받아 둔 결과를 그대로 써서 호출하지 않습니다. 위젯은 WorkManager로 3시간마다(네트워크 연결 시) 갱신하고 3시간 안의 캐시가 있으면 그대로 씁니다. 위젯이 여러 개여도 같은 위치는 한 번만 조회하므로 한 번에 많아야 2회이고, 새로고침 버튼은 20분이 지난 것만 다시 가져옵니다. 내 차 정보, 내 브랜드, 유종·반경·필터, 집·회사 위치를 바꾸면 API를 부르지 않고 캐시로 다시 그리고, 캐시가 없을 때만 조회합니다. 평균가와 7일 추이는 상세 화면을 열 때만 가져옵니다. 세 API 모두 유종과 시도를 빼고 불러서 4개 유종(과 모든 시도)을 한 번에 받고, 유종을 바꿔도 다시 부르지 않습니다. 전국 평균을 가져오지 못하면 시도별 평균은 부르지 않습니다. 그래서 평균가 관련 호출은 하루에 많아야 전국 8회, 시도별 8회(3시간마다), 7일 추이 1회로 17회입니다. 가져오지 못한 결과는 저장하지 않아서 실패하면 다음에 상세 화면을 열 때 다시 시도하고, 이때의 호출은 이 수에 더해집니다. |
| 호출 횟수 기록 | 실제 API를 호출할 때마다 오늘 호출 횟수를 기록하고 설정 화면에 표시합니다. 설정 탭은 보일 때마다 횟수를 다시 읽습니다. 화면 테마를 바꿔서 화면이 다시 만들어질 때는 ViewModel과 캐시로 그대로 다시 그리므로 API를 다시 부르지 않습니다. |
| 하루 한도 차단 | 오늘 실제 호출이 300회에 도달하면 더 이상 호출하지 않고, 주변 조회와 상세 조회 모두 한도에 도달했다는 안내를 보여줍니다. 캐시에 저장된 결과와 가짜 데이터는 계속 쓸 수 있습니다. |

## 실행 방법

### 1. 개발 환경

- Android Studio
- Java 8
- minSdk 24 (Android 7.0), targetSdk 34
- 안드로이드 기기 또는 에뮬레이터
  - 카카오맵 SDK는 ARM용 라이브러리만 제공하지만, APK에 ARM 라이브러리를 넣어 두었기 때문에 x86_64 에뮬레이터에서도 ARM 변환으로 지도가 표시됩니다 (Pixel 7, API 34에서 확인).
  - 에뮬레이터의 기본 위치는 미국이라 지도가 비어 보입니다. Extended controls의 Location에서 국내 위치(예: 강남역 37.4979, 127.0276)로 설정합니다.

### 2. API 키 발급

- **오피넷**: [오피넷](https://www.opinet.co.kr)에서 유가정보 API 무료 이용을 신청합니다.
- **카카오**: [카카오 디벨로퍼스](https://developers.kakao.com)에서 앱을 추가하고 네이티브 앱 키(지도용)와 REST API 키(검색용)를 확인합니다. Android 플랫폼에 패키지명 `com.example.findcheapgas`와 키 해시를 등록하고, 카카오맵 사용 설정을 켭니다.
  - 키 해시를 등록하지 않으면 지도가 표시되지 않습니다. 앱을 실행하면 Logcat에 키 해시가 출력됩니다.

### 3. API 키 입력

프로젝트 최상위 폴더의 `local.properties`에 발급받은 키를 추가합니다.

```properties
OPINET_API_KEY=오피넷_API_키
KAKAO_NATIVE_APP_KEY=카카오_네이티브_앱_키
KAKAO_REST_API_KEY=카카오_REST_API_키
# true면 가짜 데이터 사용, false면 실제 API 사용
USE_MOCK_DATA=true
```

`local.properties`는 GitHub에 올라가지 않습니다. API 키는 코드에 직접 작성하지 않습니다.

### 4. 빌드 및 실행

Android Studio에서 프로젝트를 열고 Gradle Sync를 한 뒤, 연결한 휴대폰이나 에뮬레이터를 선택해서 실행합니다. 처음 실행하면 내 차 정보 입력 화면이 나오고(건너뛸 수 있음), 지도 화면에서 위치 권한을 허용합니다.
